# Data Sources

## Collection criteria
- Directly about traditional Tamil tank/eri irrigation or associated agricultural/water-management knowledge.
- Trustworthy origin: peer-reviewed, government, institutional, or legally digitised books/archives.
- Licence or permission allows us to store and process the full text. Record the exact licence.
- Metadata copied from the document itself, never guessed.
